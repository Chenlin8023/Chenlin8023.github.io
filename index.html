版本历史 / 回退

  1. Sileo：对已安装的包，长按插件页的「修改 / MODIFY」按钮，弹出菜单里选择历史版本； 未安装时 Sileo 只显示最新版，这是客户端限制。
  2. Irisin / Zebra：包页的版本列表可直接选择旧版本（前提是源索引保留了这些版本）。
  3. 每个插件页的「更新日志」页签列出全部版本、变更点、验证状态和该版本 .deb 直链。
版本不是越多越好：源内保留的是可回退的稳定/历史构建；已撤回的版本只在更新日志里文字说明，不提供下载。

安装注意

  1. iphoneos-arm64e 的包不要过 RootHide 转换器：这些是原生 roothide 包， 转换器会重写二进制并破坏 arm64e 指针认证，可能导致安全模式。
  2. iphoneos-arm64 的是 rootless 包：在 RootHide 设备上需要先用 RootHide 转换器转换，或使用支持 rootless 的引导环境；普通 rootless 设备直接安装。
  3. LSTimeSeconds 已拆成两个包：RootHide 用 LSTimeSeconds (RootHide)， rootless（/var/jb）用 LSTimeSeconds (rootless)。 RootHide 从旧包升级需先卸载旧 LSTimeSeconds，再装新 ID 包；prefs 域不变，设置可保留。
  4. AppLock+ 需要手动注入：装完后用 TrollFools / JailFools 把 dylib 注入目标 App， 否则不会有任何效果。
  5. VolumeManager (Full)：1.3.0 是过渡版，用 JailFools 注入过引擎的 App 升级后需 覆盖 .app/Frameworks/VolManAudioQueue.dylib 并重开 App；1.2.0 是稳定回退版。
  6. LSTimeSeconds 不支持 AOD 暗屏走秒：系统在暗屏使用 1Hz Flipbook，应用层无法刷新； 熄屏自动暂停，亮屏立即恢复。
