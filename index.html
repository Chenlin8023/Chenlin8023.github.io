注意事项

  1. 标 iphoneos-arm64e 的包不要过 RootHide 转换器：这些是原生 roothide 包，转换器会重写二进制并破坏 arm64e 指针认证，导致安全模式。
  2. 标 iphoneos-arm64 的是 rootless 包：在 RootHide 设备上需要 先用 RootHide 转换器转换，或使用支持 rootless 的引导环境；普通 rootless 设备 则直接安装。
  3. 架构可见性：普通 rootless / rootful 设备（APT 架构为 iphoneos-arm64 / iphoneos-arm）在 Sileo 里 看不到 iphoneos-arm64e 的 roothide 包；RootHide 设备通常 同时启用两种架构，所以能看到 arm64 的 rootless 包（需转换）。
  4. AppLock+ 需要手动注入：它不是全局插件，装完后必须用 TrollFools / JailFools 把 dylib 注入到目标 App，否则不会有任何效果。
  5. LSTimeSeconds 不支持 AOD 暗屏走秒：LTPO 在 AOD 下锁 1 Hz，系统 Flipbook 会短路常规重绘。熄屏自动暂停，亮屏立即恢复。
  6. 回退版本：RootHide 用 apt install com.sini921.lstimeseconds=0.0.7-1； rootless 用 apt install com.sini921.lstimeseconds=0.0.7-4。
