MUtool 工具箱（修改版）

MUtool 多功能工具集的本地修改构建：解除授权验证、移除授权与推广界面，功能与官方版一致。

iphoneos-arm64rootless /var/jb（RootHide 实测）已验证

功能

  • 灵动岛电池胶囊与电源菜单、桌面悬浮信息药丸（网速 / CPU / 内存 / 电池 / 天气 / 时间）
  • 三合一状态栏、文件夹主题与大文件夹、状态栏文字图标变色
  • 通话自动录音与录屏增强、双卡 T9 拨号、自动禁用 SIM 与卡槽管理
  • IPCC 运营商配置、WiFi 永连、充电提示音与 MagSafe 动画、温控调优
  • 锁屏与主屏幕增强、定时任务、电池健康与深度信息、SMC 寄存器读写
  • 修改版特有：全部功能免授权直接可用，无激活 / 推广界面，不连接授权服务器

注意事项
  • 基于 Muzi 官方 MUtool 2.2.80 deb 的二进制修改构建（非源码编译）；Package id / 依赖与官方包一致。
  • rootless（/var/jb），iphoneos-arm64（内含 arm64 + arm64e 双 slice），RootHide 下安装路径与官方包相同。
  • 与官方包同 id：安装即覆盖官方版；回滚重装官方 2.2.80 即可。
  • 设置页已移除『设备授权 / 关于 / 推广』区块，各功能页不再出现未激活提示。
  • 官方声明 iOS 15–17；本包实机验证 iOS 17.2.1（iPhone 15 Pro · RootHide）。
