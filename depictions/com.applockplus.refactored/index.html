AppLock+ (应用锁+)

按应用注入式应用锁，6 位密码 + Face ID / 触控 ID，免 substrate。

iphoneos-arm64eRootHide（按应用注入，免 substrate）已验证

功能

  • 按应用注入：适合会检测越狱、无法全局注入的 App（TrollFools / JailFools）
  • 6 位应用锁密码；首次启动强制设置，不使用默认 0000
  • Face ID / 触控 ID 作为快捷方式；取消、失败或识别不可用时停留在密码键盘，不放行
  • 密码 PBKDF2-SHA256（2 万次迭代 + 16 字节随机盐），优先存 Keychain；恒定时间比较
  • 连续输错 5 次起指数冷却（1→2→4…分钟，上限 17 小时），状态持久化，杀进程不重置
  • 后台快照模糊遮盖；双指双击进入设置；支持 UIWindowScene / SwiftUI
  • 载体包：dylib 需手动注入目标 App，装完不会全局生效

注意事项
  • 载体包：dylib 位于 /var/mobile/Documents/AppLockPlus/，用 Debs 导出或 Filza 取出，再由 TrollFools / JailFools 注入目标 App。
  • 不要过 RootHide 转换器；本包是免 substrate 的按应用注入 dylib。
  • 构建目标 iOS 14+；实机验证为 iPhone 15 Pro / iOS 17.2.1。
