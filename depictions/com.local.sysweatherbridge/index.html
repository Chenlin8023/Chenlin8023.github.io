SysWeatherBridge（系统天气桥）

自动定位并把经纬度写入 MUtool 的 open-meteo 天气参数，免去手动填写；MUtool 修改版 2.2.80-11 起自动依赖。

iphoneos-arm64rootless /var/jb（RootHide 走转换器）未单独验证（与 0.3.4 同一二进制，仅打包形态改为 rootless）

功能

  • 自动定位：GPS（可用时）→ IP 定位（pconline / ipip / 淘宝多源投票，城市级）→ 天气缓存坐标兜底
  • 多源投票：与上次位置 ≤200km 直接采纳；跨城需 ≥2 个 IP 源互差 ≤50km 且连续两次确认（间隔 ≥10 分钟），单源异常不会把天气带跑
  • 把两位小数的经纬度写入 com.muzi.mutoolprefs 并发送 ReloadPrefs，MUtool 药丸立即按新坐标拉取 open-meteo
  • 每 30 分钟复查定位；天气本体仍由 MUtool 按自身节拍刷新
  • 零 block、零编译期 ObjC 类，不 hook 任何方法，只在 SpringBoard 内运行

注意事项
  • rootless（/var/jb），iphoneos-arm64，内含 arm64 + arm64e 双 slice；RootHide 通过转换器安装（与 MUtool 本体同路径）。
  • MUtool 修改版 2.2.80-11 起自动依赖本包；单独安装无副作用，不修改任何插件本体。
  • SpringBoard 的 GPS 被 TCC 限制（未授权），实际使用 IP 定位，精度为城市级；同城不变化，跨市/跨省 10–30 分钟内跟上。
  • 从旧 roothide 原生 0.3.4 升级：先 dpkg -r --force-depends com.local.sysweatherbridge，再安装本包。
